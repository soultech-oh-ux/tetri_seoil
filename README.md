# 한국어 테트리스

외부 라이브러리와 서버 없이 실행되는 HTML 블록 퍼즐입니다.

## 실행

index.html 파일을 브라우저로 열고 '새 게임'을 누르세요.

## 조작

- 왼쪽 / 오른쪽 방향키: 이동
- 위쪽 방향키: 회전
- 아래쪽 방향키: 빠르게 한 칸 내리기
- 스페이스: 즉시 낙하
- P: 일시정지 또는 계속하기
- Enter: 새 게임
- 휴대전화: 화면 아래 버튼 사용

## 기능

7종 블록을 한 묶음씩 섞어서 생성, 다음 블록 미리보기, 착지 위치 표시,
점수와 레벨, 줄 삭제, 최고 점수 저장, 화면을 벗어나면 자동 일시정지.
최고 점수는 해당 브라우저에 저장됩니다. 저장이 제한되어도 게임은 실행됩니다.
회전 시 좌우 공간 보정을 지원하며 공식 SRS 회전 규칙의 완전한 구현은 아닙니다.
